# Data Science Portfolio

Source of my portfolio site, published with **GitHub Pages** from the `main` branch, root folder.

**Live site:** https://wangtingyue0322-beep.github.io/data-science-portfolio/

## What is in here

| Path | Purpose |
|---|---|
| `index.md` | the site entry page — profile, skills and project showcase |
| `figures/` | the two visualisations embedded in the showcase |
| `_config.yml` | GitHub Pages / Jekyll settings |

## The project behind the showcase

[**data-science-project**](https://github.com/wangtingyue0322-beep/data-science-project) — *Growth at the
top, erosion at the bottom: U.S. family income, 1972–2016*. Notebook, data extract, requirements
file and four figures; the README reproduces every number in the analysis.

## Editing this site

The page is Markdown rendered by Jekyll. To change it, edit `index.md`, commit, and push to `main` —
GitHub Pages rebuilds within a minute or two.
